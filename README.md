# Movie Search 
## My first project using React + Tailwind 

Movie Search APP where you can find trending movies, search for you own ones or get recommendations by genre. Once clicked on movie you can also find out about it's rating, cast team or watch movie's trailer. Data is received through TMDB API, where you need to sign up to receive key. 

### Technologies used:
*  React
*  Tailwind
*  Git
*  TMDB API

## How to run? 
1.  Clone the project
2.  Install packets -> npm install
3.  Create .env file with API Key
4.  Finally run -> npm run dev
